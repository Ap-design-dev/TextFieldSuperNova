Согласовано 13 ноября 2026 года. Источники: [состояния](https://www.figma.com/design/l1Mc2dfm0aVfw93T8GmmuM/?node-id=3-27), [дополнения](https://www.figma.com/design/l1Mc2dfm0aVfw93T8GmmuM/?node-id=9-1497) и подтверждения заказчика в чате.

## Состояния

| Режим | Пусто, без фокуса | Пусто, с фокусом | Сумма, с фокусом | Сумма, без фокуса |
|---|---|---|---|---|
| Обычный | Empty | Default | Active | Filled |
| Error | Error Empty | Error Default | Error Active | Error Filled |
| Warning | Warning Empty | Warning Default | Warning Active | Warning Filled |

Ещё пять вариантов: Read Only, Error Read Only, Warning Read Only, Disabled, Skeleton. Итого 17. Состояния фокуса выводятся из реального ввода; Error/Warning задаёт приложение.

## Сумма и каретка

- Только целые неотрицательные рубли, без копеек. В модель передаётся строка цифр без разделителей и ₽. Ноль нормализуется к пустой строке; на экране отображается серое `0 ₽`.
- Каждый обычный тап по сумме или шеврону включает ввод и ставит каретку в конец числа, перед ₽. Повторный тап во время ввода также ставит каретку в конец.
- Толщина каретки — 2 единицы макета: CSS px в предпросмотре, pt/dp в нативных платформах. Синяя рамка у поля суммы в предпросмотре удалена; настройки используют обычные фокусные индикаторы браузера.
- Знак ₽ — постоянный суффикс вне редактируемого числа.
- Группы тысяч разделяются неразрывным пробелом U+00A0, включая активный ввод.
- Крестик виден только во время ввода, очищает до `0` и сохраняет фокус/клавиатуру. Крестик можно скрыть отдельно от шеврона.
- Шеврон виден без фокуса, обозначает редактируемость и включает редактирование. При фокусе он скрывается; его видимость можно отключить отдельно.
- Вставка целой суммы с разделителями и ₽ допустима. Дроби, знак минус, буквы и экспоненциальная запись отклоняются целиком.
- Ограничения минимальной/максимальной суммы задаёт приложение; модель не преобразуется в Float/Double/Int.
- При нехватке ширины шрифт уменьшается с базовых 42 до 21, затем число прокручивается горизонтально. Переноса суммы нет. При системном масштабировании нативного шрифта нижняя граница составляет 50% его базового размера.
- На iOS над цифровой клавиатурой предусмотрено «Готово». Потеря фокуса завершает ввод; на Android закрытие открытой клавиатуры также снимает фокус.

## Suggest

- Выбор подсказки заменяет значение и сохраняет ввод и клавиатуру; при выборе без фокуса ввод включается.
- При точном совпадении суммы выделяется соответствующий Suggest, независимо от того, выбрана ли подсказка или значение введено вручную.
- При изменении суммы выделение сразу обновляется или снимается. У пустого значения подсказка не выделяется.
- Выбранный Suggest: фон `#3B3B3E`, белый текст. Обычный: фон `#F2F4F7`, текст `#1F1F22`.

## Read Only, Disabled и Skeleton

- В Read Only и Disabled пользователь не может изменить сумму ни через поле, ни через Suggest. Иконок редактирования нет, клавиатура не открывается. Значение может обновлять само приложение.
- В обычных Read Only и Disabled подсказки видны, но неактивны. В Error Read Only и Warning Read Only они скрыты.
- Read Only сохраняет обычную насыщенность суммы; Disabled использует `#1F1F22` с прозрачностью 35% для подписи, суммы и описания. Подсказки сохраняют исходные цвета макета.
- Skeleton заменяет содержимое оригинальными элементами из Figma, не меняет сохранённую сумму и не допускает ввода. Мерцание в макете не задано; анимация не добавлена.
- При переключении в недоступный режим ввод завершается. Disabled и Skeleton имеют приоритет над Error/Warning.

## Error и Warning

- Приложение передаёт состояние и текст сообщения, определяет условия появления и снимает состояние явно. Ввод, очистка и выбор Suggest сами не снимают сообщение.
- Error (`#D10032`) и Warning (`#EF4C01`) заменяют обычное описание. Цвет суммы остаётся зависимым от пустоты/заполненности.
- Оба сообщения поддерживают явные переносы строк (`\n`) и автоматический перенос по ширине. Высота блока растёт по содержимому, без ограничения числа строк. В настройках предпросмотра перенос вводится клавишей Enter.
- В предпросмотре режим сообщения и его текст переключаются вручную; к конкретным суммам ошибки не привязаны.

## Настройки и размеры

- Label и Description принимают пользовательский текст, поддерживают многострочность и независимое скрытие. В Figma показаны примеры подписи в две строки и описания в три; жёсткий лимит строк не задан.
- Suggest скрывается пустым списком, Label/Description — `nil`/`null`. Скрытый Description скрывает также его Error/Warning-сообщение.
- Отступы настраиваются параметром spacing; исходные значения соответствуют Separator из Triplex Next.
- Базовая ширина — 375 pt/dp; высота полного обычного варианта — 186, Skeleton — 176 при обычном размере шрифта. Высота растёт при многострочном тексте.
- Сумма: SB Sans Display Semibold, 42/50. Label: SB Sans Text Regular, 14/20; Description: 14/16; Suggest: 12/16.
- Основной текст: `#1F1F22`; пустая сумма/описание: 65%. Первая версия палитры остаётся светлой, как в макете.
- Внешние вертикальные отступы 24; после подписи и суммы по 4; до подсказок 12, после 4; между подсказками 10. Кнопка: внутренние отступы 12 × 6, радиус 6.
- Шеврон 14 × 15, крестик 16 × 16. Skeleton: подпись 170 × 10, сумма 230 × 20, описание 130 × 8, подсказка 96 × 28.

## Приёмка

1. Проверить Empty → Default → Active → Filled, затем повторный вход в поле. Каждый тап ставит каретку в конец, перед ₽.
2. Ввести вручную `1000000`: второй Suggest выделен. Дописать цифру: выделение снято. Выбрать Suggest: значение заменено, клавиатура открыта.
3. Очистить крестиком: серое `0 ₽`, каретка и клавиатура остаются, выделенного Suggest нет.
4. Повторить ввод с Error и Warning: сообщение приложения не исчезает. Явно снять сообщение.
5. Проверить Read Only и Disabled: тап, клавиатура и подсказки не изменяют сумму. В Read Only с Error/Warning подсказок нет.
6. Включить Skeleton и вернуться к обычному режиму: сохранённая сумма восстановлена.
7. Заполнить Label/Description многострочными текстами и скрыть каждый блок отдельно. Скрыть шеврон и крестик независимо; ввод через сумму продолжает работать.
8. Вставить очень длинное целое число: уменьшение останавливается на половине базового размера, далее работает прокрутка. Сумма не теряется и не переносится.
9. Проверить вставку целых сумм с пробелами/₽; отклонение дробей, отрицательных значений и букв.
10. На обеих платформах проверить узкий экран, системный масштаб шрифта, реальную клавиатуру, VoiceOver/TalkBack и снять нативные скриншоты для сравнения с Figma.
