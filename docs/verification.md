# Проверка версии 0.2

Дата основной проверки: 13 ноября 2026 года. Многострочные сообщения проверены 14 ноября 2026 года.

## Выполнено локально

- Подтверждены семейства шрифтов: SB Sans Text Regular (`SBSansText-Regular`) и SB Sans Display Semibold (`SBSansDisplay-Semibold`). Копии в ресурсах обеих платформ совпадают с оригиналами.
- Все семь файлов пользователя сохранены без изменений. Четыре элемента Skeleton скачаны по адресам, выданным Figma, без перерисовки.
- Шесть SVG экспортированы через Sharp в 48 PNG: iOS 1x/2x/3x, Android mdpi–xxxhdpi. Проверены геометрия, наличие непрозрачных пикселей, ссылки в каталогах ресурсов и JSON/XML.
- Скрипт браузерного предпросмотра разобран JavaScript-движком без синтаксических ошибок.
- Из реального скрипта предпросмотра извлечена и выполнена функция нормализации: прошли 12 проверок целых сумм, разделителей, ведущих нулей, очень длинного значения и отклонения дробей, минуса, букв и экспоненциальной записи. Это проверки логики, не системного буфера обмена.

## Проверено интерактивно в браузерной модели

- Ручной ввод `1000000` выделяет второй Suggest; изменение суммы снимает выделение.
- Повторный тап после перемещения каретки возвращает её в конец: дописанная цифра оказывается последней.
- Выбор Suggest и очистка сохраняют фокус; поле возвращается к `0`.
- Error сохраняется при вводе, Error Read Only скрывает Suggest. Обычный Read Only показывает недоступные подсказки; Disabled также блокирует поле.
- Skeleton отображает оригинальные элементы и убирает интерактивное содержимое.
- Текстовые настройки меняют Label и Description, включая несколько строк. Можно задать текст Warning и скрыть блоки/иконки независимо.
- Для Error и Warning проверен ввод переносов через Enter в поле «Текст сообщения», сохранение разных многострочных текстов при переключении состояния и автоматический перенос длинной строки в самом компоненте. Высота растёт без наложения на Suggest. В SwiftUI явно отключён лимит строк сообщения, в Compose включён softWrap; нативная сборка повторно не запускалась из-за отсутствия инструментов.
- Очень длинная сумма остаётся целой строкой и прокручивается в ограниченной области. У поля суммы нет синей рамки; пользовательская каретка задана шириной 2 CSS px.

Это проверка отдельной браузерной модели. Она не исполняет Swift/Kotlin и не подтверждает поведение мобильной клавиатуры.

## Ещё не выполнено

- Нативная компиляция SwiftUI/UIKit и Android-модулей: в окружении нет Xcode, JDK и Android SDK.
- Запуск XCTest/JUnit и инструментальных тестов. Добавлены проверки совпадения Suggest, видимости в Read Only и сохранения внешнего сообщения; результаты запуска отсутствуют.
- Проверка жестов каретки, прокрутки, системного масштаба шрифта, клавиатуры и accessibility на устройствах.
- Нативные скриншоты 17 вариантов и их сравнение с Figma.

Workflow `.github/workflows/native-checks.yml` подготовлен для сборки и тестов при загрузке в GitHub. Текущие результаты удалённой проверки доступны в [GitHub Actions](https://github.com/Ap-design-dev/TextFieldSuperNova/actions). Локальные проверки выше не подтверждают нативную сборку. Архив содержит исходники для проверки, а не подтверждённую production-сборку.
