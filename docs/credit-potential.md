# Credit Potential — версия 0.3

Источники: [8 состояний](https://www.figma.com/design/l1Mc2dfm0aVfw93T8GmmuM/?node-id=15-1940), [поведение и скрытие элементов](https://www.figma.com/design/l1Mc2dfm0aVfw93T8GmmuM/?node-id=18-2406), уточнения пользователя от 14 ноября 2026 года.

Новый компонент использует существующий механизм TextField SuperNova: целые неотрицательные рубли, постоянный суффикс ₽, группировку тысяч, каретку в конце при каждом тапе, очистку с сохранением клавиатуры и масштаб 42 → 21 с последующей горизонтальной прокруткой. Каретка остаётся 2 логические единицы по уточнению пользователя, хотя в Figma нарисована 3.

Сумма центрирована независимо от иконки. Под ней расположены многострочный текст (Text Regular 14/20) и кнопка-ссылка (Text Semibold 14/20, #008985). Текст и кнопка скрываются независимо через nil/null; шеврон и крестик — отдельными флагами. Ноль отображается серым. Верхней подписи и Suggest в этом виде нет.

Режимы: Editable, Read Only, Skeleton. Warning передаётся приложением отдельной строкой, заменяет пояснение и окрашивает его в #EF4C01; ввод/очистка не снимают Warning. При скрытом тексте Warning также скрыт. Лимита числа строк нет; явные переносы и перенос по ширине сохраняются. Error и Disabled в новых макетах не заданы и в API нового вида не добавлены.

Восемь примеров Figma: Default (заполнено, фокус), Filled, Read Only, Warning Active, Warning Filled, Warning Empty, Warning Read Only, Skeleton. Дополнительные сочетания пустоты и фокуса обрабатываются общим вводом. В Read Only сумма недоступна для редактирования, иконки скрыты, а кнопка информации работает. Skeleton не вызывает действие кнопки и не изменяет сохранённую сумму.

Кнопка вызывает обязательный обработчик `onInformation`. Приложение открывает пуллер или страницу и управляет клавиатурой при переходе. Сам компонент не меняет сумму, Warning или фокус в обработчике кнопки. Примеры платформ показывают пуллер; браузерная модель позволяет выбрать пуллер/страницу с демонстрационным заголовком.

## Геометрия

Базовая ширина 375. Сумма имеет строку 50, Skeleton суммы — 40. Отступ до нижнего блока 4, нижний отступ 32. У кнопки вертикальные отступы 6 + 6 вокруг строки 20. При скрытых тексте и кнопке разделитель 4 убирается: после суммы остаётся ровно 32 (уточнение пользователя).

| Текст | Кнопка | Высота | Skeleton |
|---|---|---:|---:|
| Да | Да | 138 | 128 |
| Да | Нет | 106 | 96 |
| Нет | Да | 118 | 108 |
| Нет | Нет | 82 | 72 |

Высоты приведены при обычном размере шрифта и одной строке текста/кнопки. Три строки пояснения увеличивают полный компонент до 178. Отступы настраиваются `SuperNovaCreditSpacing`.

Skeleton использует оригинальные SVG Figma: сумма 230 × 20 (побайтно совпадает с существующим ресурсом), текст 170 × 10, кнопка 102 × 8. SVG не перерисовывались. Анимация не задана. Новый файл SB Sans Text Semibold подключён с PostScript-именем SBSansText-Semibold; синтетическое утолщение не используется.

## Подключение

```swift
SuperNovaCreditPotential(
    amount: $amount, isEditing: $editing,
    text: "Кредитный потенциал\nДополнительные условия",
    buttonTitle: "Подробнее", mode: .readOnly,
    warning: nil
) {
    showsInformation = true // .sheet или navigationDestination в приложении
}
```

```kotlin
SuperNovaCreditPotential(
    state = amount,
    onInformation = { showsInformation = true },
    text = "Кредитный потенциал\nДополнительные условия",
    buttonTitle = "Подробнее",
    mode = SuperNovaCreditMode.ReadOnly,
)
```

Для скрытия обоих нижних элементов задайте `text: nil, buttonTitle: nil` / `text = null, buttonTitle = null`. Исходный компонент и его правила отступов сохраняются.
